学校官网首页与智慧校园综合门户
本仓库为"AI 数字设计——中高一体项目化实训教程"工作任务 2-3（VibeCoding 网页设计）的成果交付物。
一、项目说明
本项目将《学校官网首页》与《智慧校园综合门户》两份设计稿，转化为可在手机、平板、电脑三类终端自适应访问的响应式网页。
- index.html：学校官网首页（由 campus-home.html 重命名而来，是 GitHub Pages 的入口文件）
- campus-portal.html：智慧校园综合门户
技术实现：原生 HTML + CSS + JavaScript，无构建步骤，浏览器直接打开即可预览；通过媒体查询实现三档断点（手机 / 平板 / 电脑）适配。
二、AI 使用说明
- 由 AI 生成的部分：页面整体结构、基础样式与响应式断点，由 VibeCoding（AI 辅助编程）依据设计稿与提示词生成；
- 人工修改的部分：对 AI 生成代码的参数级调整、文案核对、缺陷修复与可读性优化（详见实训任务二 Step 3 人工精修、任务四缺陷修复）；
- 所用提示词：见实训任务二（描述与生成）。
